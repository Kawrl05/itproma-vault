# WBS Practice Template — 3-Level (Blank)

Use this to practice building a 3-level WBS for any software/service delivery project. Fill in Level 2 and Level 3 for your chosen project.

## Outline View
```
1.0  [PROJECT NAME]                          ← Level 1
  1.1  [Major Deliverable / Phase A]          ← Level 2
    1.1.1  [Sub-deliverable / Work Package]   ← Level 3
    1.1.2  [Sub-deliverable / Work Package]
  1.2  [Major Deliverable / Phase B]          ← Level 2
    1.2.1  [Sub-deliverable / Work Package]
    1.2.2  [Sub-deliverable / Work Package]
  1.3  [Major Deliverable / Phase C]          ← Level 2
    1.3.1  [Sub-deliverable / Work Package]
    1.3.2  [Sub-deliverable / Work Package]
```

## Table Format
| WBS Code | Task/Deliverable | Level | Resources | Dependencies | Effort (hrs) |
|---|---|---|---|---|---|
| 1.0 | | 1 | | | |
| 1.1 | | 2 | | | |
| 1.1.1 | | 3 | | | |
| 1.1.2 | | 3 | | | |
| 1.2 | | 2 | | | |
| 1.2.1 | | 3 | | | |

## Self-Check Before Submitting
- [ ] Level 1 = project name only
- [ ] Level 2 items are **deliverables/phases**, not actions
- [ ] Level 3 items are specific enough to estimate cost/duration (approaching work-package size)
- [ ] 100% Rule – every piece of scope is represented somewhere
- [ ] No dependencies shown (that belongs on a Gantt chart)
- [ ] Each item has exactly one clear owner
