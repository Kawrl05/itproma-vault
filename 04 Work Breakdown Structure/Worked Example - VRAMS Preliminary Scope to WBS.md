# Worked Example: VRAMS-Mobile — Preliminary Scope → 3-Level WBS

The charter's preliminary scope statement lists 5 items. Here's how those become Level 2 of a WBS, decomposed to Level 3:

```
1.0  VRAMS-Mobile Project
  1.1  App Design, Implementation, Testing & Deployment
    1.1.1  Design mobile UI (iPhone, iPad, Galaxy Android)
    1.1.2  Implement core booking/appointment features
    1.1.3  Integrate with existing VRAMS web server
  1.2  Test & Acceptance Criteria Development
    1.2.1  Draft prototype test criteria (with technical committee)
    1.2.2  Draft full-app acceptance criteria
  1.3  Project Team Organization & Management
    1.3.1  Assign in-house J2EE developers (train for iOS/Android)
    1.3.2  Coordinate resources with IT Department Manager
  1.4  Project Management Plan Development
    1.4.1  Build schedule (prototype: wk 12; full app: wk 24)
    1.4.2  Build budget tracking ($252,000 incl. contingency)
  1.5  Systems Management Manual Development
    1.5.1  Draft technical documentation
    1.5.2  Draft systems management manual
```
