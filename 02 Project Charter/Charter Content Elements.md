# Project Charter — Content Elements (PMBOK)

| Element | What It Does |
|---|---|
| Purpose & justification | Why the project exists |
| Objectives | Results to achieve (scope, schedule, cost, quality...) |
| Success criteria | Measurable indicators the objective was met |
| High-level requirements | Initial business/compliance requirements |
| Assumptions & constraints | Initial limits (budget, due date, etc.) |
| High-level project description | Summary of project & approach |
| High-level risks | Initial risks (feeds the risk register) |
| Summary milestones | Major events/phases |
| Summary budget | Rough expenditure range |
| Stakeholder list | Initial stakeholders |
| Approval requirements | Who signs off, and criteria |
| PM authority | Staffing, technical decisions, conflict resolution, budget management |
| Signatures | Sponsor, PM, other approvals |
