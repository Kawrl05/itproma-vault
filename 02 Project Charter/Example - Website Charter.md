# Worked Example: Website Project Charter (Widgets.com)

**Vision:** On-time delivery of a robust website with strong SEO that sells products simply.

**Business case:** Extend Widgets Manufacturing's reach beyond retail, cost-effectively, via e-commerce.

**Timeline:** ~6 months, live before year-end (seasonal buying).

**Budget:** $1,000,000.

**Key risks:** Too many decision-makers slowing progress, staff turnover, scope creep, graphic/content fine-tuning delays.
