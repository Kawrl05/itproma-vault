# Worked Example: Pac-Man RACI Matrix (Waterfall)

| Task | PM | Game Designer | Developer | QA Tester | IT Support |
|---|---|---|---|---|---|
| Define Game Requirements | R, A | C, I | | | I |
| Design Game Architecture | | C | R, A | I | I |
| Code Game Mechanics | | I | R, A | C | |
| Conduct Functional Testing | I | | C | R, A | |
| Execute Game Launch | R, A | | I | | C |
| Provide Ongoing Support | R | | I | | C, A |

**How to read it:** one **A** per row (accountable owner); **R** can be shared; **C** = two-way input before the work is done; **I** = one-way, after the fact.
