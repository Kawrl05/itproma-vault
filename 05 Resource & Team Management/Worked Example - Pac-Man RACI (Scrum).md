# Worked Example: Pac-Man RACI Matrix (Scrum)

| Task | Product Owner | Scrum Master | Dev Team | QA |
|---|---|---|---|---|
| Define User Stories | A | C | R (Game Developer) | I |
| Develop Basic Movement | C | I | R | R |
| Sprint Review & Retrospective | A | R | C | C |
| Conduct Regression Testing | C | I | R | A |

**Role notes:**
- **Product Owner** – Accountable for vision & backlog priority
- **Scrum Master** – Responsible for facilitating Scrum ceremonies, removing blockers
- **Development Team** – Responsible for building the increment each sprint
- **QA** – functionally part of the Dev Team in Scrum; Responsible for testing, sometimes Accountable for release-readiness
