# Focus 2: WBS Practice

Goal: be able to build a **3-level WBS** for a software or service delivery project from scratch.

## Study Order
1. Read the full theory → [[WBS Comprehensive Guide]]
2. Try the blank template yourself → [[WBS Practice Template (Blank)]]
3. Check your work against the worked examples:
   - [[Worked Example - Pac-Man WBS (Waterfall)]] (phase-based, SDLC)
   - [[Worked Example - Pac-Man WBS (Scrum)]] (sprint-based, Agile)
   - [[Worked Example - VRAMS Preliminary Scope to WBS]] (charter → WBS)

## Self-Test
- Can you explain the **100% Rule** in one sentence?
- Can you name the difference between **deliverable-based** and **phase-based** WBS?
- Can you explain the **8/80 rule** for work packages?
- Given a random software project prompt, can you produce Levels 1–3 in under 10 minutes?
