# Focus 3: SMART Objectives Practice

Goal: draft **fully expanded** SMART objectives (not just vague goals) with explicit measurable criteria.

## Study Order
1. Read → [[SMART Objectives Guide]]
2. Study the worked examples:
   - [[Worked Example - VRAMS-Mobile SMART Objectives]]
   - [[Worked Example - E-Commerce Site SMART Objectives]]
   - [[Worked Example - Construction Project SMART Objectives]]
3. Practice: pick any project goal from your notes and expand it into a full SMART statement using the checklist in the guide.

## Self-Test
- For each objective you write, can you point to the exact word/phrase that makes it S / M / A / R / T?
- Do your objectives include a **number** (percentage, dollar amount, date, or count)?
