# 1. Project Integration Management

The framework for coordinating **tasks, resources, stakeholders, and changes**. Key tool: the project management plan (roadmap, approved by stakeholders/sponsors, tracked by the PMO).

Includes directing/managing project work (producing deliverables), monitoring/reporting, change control, and project closure.
