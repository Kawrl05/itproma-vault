# 3. Project Time Management

Estimating duration, creating a schedule, and tracking progress to finish on time.

**Steps:** define scope → sequence tasks & note dependencies (FS, FF, SS, SF) → estimate resources/duration → determine critical path & float → build schedule → resource leveling → control schedule (earned value management).
