# 2. Project Scope Management

Managing the **work that needs to be executed** in a project.

- Build a **scope management plan**
- Write a **scope statement**
- Create a **[[Work Breakdown Structure (Definition)|WBS]]**
- **Validate scope** – confirm deliverables are approved by sponsor/stakeholder (Monitoring & Controlling)
- **Control scope** – manage changes to the scope baseline
