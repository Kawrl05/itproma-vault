# Project

A **project** is a temporary endeavor undertaken to achieve a specific objective, using a limited set of resources within a finite timeline.

- **Temporary** – has a defined start and end
- **Unique** – produces a distinct product, service, or result
- **Progressively elaborated** – details are refined as the project moves forward

> Projects happen in daily life too (e.g., grocery shopping, planning a trip). Success = meeting objectives within time and budget, and trade-offs are common.
