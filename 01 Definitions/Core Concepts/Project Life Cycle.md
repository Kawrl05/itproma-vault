# Project Life Cycle

The series of phases a project passes through, from start to finish. Works together with [[Process Groups]] — process groups are "horizontal" (chronological), knowledge areas are "vertical" (technical subject matter).

**Six phases of an IT project (per ProjectManager.com):**
1. Initiation – define objective, write project proposal/business plan, feasibility study
2. Definition – finalize objectives & requirements, outline scope, create project plan, set budgets
3. Planning
4. Execution
5. Monitoring & Controlling
6. Closure
