# Project Management

The process that allows project managers to **plan, execute, track, and complete** projects with the help of a project team, applying principles, skills, methodologies, and tools throughout the project lifecycle.

**Five key components:**
1. Initiation – define objectives & feasibility
2. Planning – outline tasks, timelines, resources, budgets
3. Execution – implement the plan
4. Monitoring & Controlling – track progress against the plan
5. Closure – deliver final output, obtain stakeholder approval

## Key Benefits
- Improved planning & organization
- Enhanced communication
- Increased efficiency
- Higher quality deliverables
- Better time management
- Cost control
