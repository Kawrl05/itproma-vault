# Process Groups (PMI)

The **five chronological phases** every project moves through per PMI's PMBOK:
1. Initiating
2. Planning
3. Executing
4. Monitoring & Controlling
5. Closing

Different from [[10 Knowledge Areas MOC|Knowledge Areas]]: process groups = *when* work happens; knowledge areas = *what* technical subject is being managed.
