# RACI Matrix (Responsibility Assignment Matrix / RAM)

A grid showing **who does what** on each work package/activity. One axis = team members, other axis = tasks; the intersection shows each person's role.

- **R – Responsible:** does the work
- **A – Accountable:** owns/approves the outcome (only one A per task)
- **C – Consulted:** gives input (two-way communication)
- **I – Informed:** kept in the loop (one-way communication)
