# Work Breakdown Structure (WBS) — Quick Definition

A **hierarchical, deliverable-oriented** breakdown of the total scope of a project into smaller, manageable components.

- Defines **deliverables, not actions**
- Follows the **100% Rule** – all project work must be included
- Does **NOT** show dependencies (that's the Gantt chart's job)
- Foundation for scheduling, cost estimating, and resource planning
