# Iterative vs. Incremental Development

- **Iterative:** software is built in successive cycles, each a full mini development process (plan → design → build → test → deploy); a new version is produced each iteration until the product is optimal.
- **Incremental:** the product is built and delivered in functional pieces/increments that add up to the complete system.

Both are core to [[Agile Methodology]].
