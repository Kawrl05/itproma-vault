# Scrum Methodology

A specific Agile framework emphasizing **teamwork, accountability, iterative progress**.

- Divides work into fixed-length **sprints** (typically 2–4 weeks)
- Each sprint delivers a **potentially shippable increment**
- Key roles: **Product Owner** (A – owns vision/backlog), **Scrum Master** (facilitates process), **Development Team** (R – builds the increment)
- Ends each sprint with a **Sprint Review & Retrospective**
