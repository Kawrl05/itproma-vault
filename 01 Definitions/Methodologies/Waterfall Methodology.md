# Waterfall Methodology

A **traditional, linear/sequential** approach — each phase must finish before the next begins. Codified by Dr. Winston W. Royce in 1970. The go-to methodology for most IT projects.

**Six stages:**
1. Requirements
2. Design
3. Implementation
4. Testing
5. Installation (Deployment)
6. Maintenance
