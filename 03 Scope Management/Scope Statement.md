# Project Scope Statement

Written confirmation of the results the project will produce, and the constraints/assumptions the team works under. Both requester and team must agree before work begins.

**Should include:**
- **Justification** – business need
- **Product scope description** – characteristics of the product/service/result
- **Acceptance criteria** – conditions deliverables must meet
- **Deliverables** – what the project will produce
- **Project exclusions** – what's explicitly NOT included
- **Constraints** – restrictions on approach, timing, cost
- **Assumptions** – things assumed true (may turn out false)

**7-part outline for writing one:**
1. Project Goals & Objectives
2. Project Requirements
3. Project Scope Description
4. Project Exclusions
5. Project Constraints
6. Project Assumptions
7. Project Deliverables
