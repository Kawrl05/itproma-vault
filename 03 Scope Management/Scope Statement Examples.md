# Scope Statement Examples (Comparison)

| | Construction (Apartments) | Manufacturing | E-Commerce Site |
|---|---|---|---|
| **Goal** | Build revenue-generating apartment complex | Create finished product from market research | Fully functional online store |
| **Top constraints** | Time, scope, cost + env/regs | Production capacity, resources, demand | 6-month deadline, ₱800,000 cap, 1,000-item catalog cap, PH data privacy law |
| **Key assumption** | Weather, supplier availability | Cross-dept input compiled | Client supplies all content; gateway approval on standard timeline |

**E-Commerce deliverables:** wireframes/mockups, functional site (cart, payment, tracking), admin dashboard, documentation, security/performance test reports, staff training.

**E-Commerce exclusions:** native mobile app, ongoing social media management, hosting/domain renewal beyond year 1, custom third-party ERP/CRM integrations.
